# Модуль "Website Custom Modal"

Модуль `website_custom_modal` добавляет в Website Builder переиспользуемый сниппет модального окна с отдельным настраиваемым триггером (кнопка/ссылка), который можно переносить в разные редактируемые зоны страницы.

## Функциональность

- Сниппет "Button + Popup (Custom Modal)" для Website Builder.
- Модалка с редактируемым контентом (`oe_structure`) и поддержкой стандартных блоков Odoo.
- Гибкие настройки модалки:
  - позиция (`Top`/`Middle`/`Bottom`);
  - backdrop (вкл/выкл + цвет);
  - ширина и высота (preset + custom).
- Гибкие настройки триггера:
  - режим `Button`/`Link`;
  - для кнопки: variant/size/shape/width;
  - для ссылки: color/underline/weight/size.
- Поддержка переноса триггера из обертки модалки в другие inline-зоны страницы.
- Открытие модалки по hash-ссылке (`href="#modalId"`).

## Системные требования

- Odoo 17

## Модульные зависимости

- `website`
- `web_editor`

## Python-зависимости

Дополнительные Python-библиотеки для данного модуля не требуются.  
Файл `requirements.txt` не используется.

## Установка

1. Скопировать модуль `website_custom_modal` в директорию `addons`.
2. Перезапустить сервис Odoo.
3. Включить debug режим:
   - `http://<host>:8069/web?debug=true`
4. Перейти в "Приложения", обновить список приложений.
5. Установить модуль `website_custom_modal`.
6. При обновлениях кода выполнить обновление модуля:
   - `-u website_custom_modal`

## Использование

### Добавление сниппета

- В Website Builder открыть панель сниппетов.
- Добавить сниппет `custom modal`.
- Сниппет создаёт триггер и модальное окно с редактируемым содержимым.

### Настройка модального окна

- Кликнуть по модалке/обертке сниппета.
- В snippet options доступны:
  - Position (`Top`/`Middle`/`Bottom`);
  - Backdrop (вкл/выкл, цвет);
  - Modal Width/Height (preset и custom значения).
- Для custom размеров доступны поля:
  - `Custom Width` (например: `640px`, `75%`, `48rem`);
  - `Custom Height` (например: `420px`, `70vh`).

### Настройка триггера

- Кликнуть по триггеру (`Open modal`) и открыть его панель опций.
- Выбрать `Trigger Mode`:
  - `Button` — доступны variant/size/shape/width;
  - `Link` — доступны color/underline/weight/size.
- Опция `Trigger Align` применяется для триггера внутри обертки модалки.

### Перенос триггера в другое место

- Триггер можно перетащить из блока сниппета в другую inline-зону страницы.
- После переноса триггер сохраняет связь с модалкой через `href="#modalId"`.
- Можно создать несколько триггеров, указывающих на одну модалку.

### Открытие модалки на странице

- Клик по триггеру меняет hash URL и открывает модалку с соответствующим `id`.
- Модалка работает на той странице, где размещен сниппет.
